
# ShellForge

ShellForge is a Unix-like shell developed as part of the Operating Systems and Systems Programming Project.

## Features (Week 1)

* Interactive REPL loop
* Makefile-based build
* Git repository
* Linux development environment

## Build

```bash
make
```

## Run

```bash
make run
```

## Week 2 Features

* Dynamic command input
* Memory allocation using malloc()
* Automatic buffer expansion using realloc()
* Proper memory cleanup using free()

## Week 3 Features

* Command parsing
* Tokenization using strtok()
* Commands converted into argv[] tokens
* Dynamic token array
* Proper memory cleanup using free_tokens()

## Week 4 Features

* Process creation using fork()
* Command execution using execvp()
* Parent process synchronization using waitpid()
* External Linux command execution
* Error handling for invalid commands

## Week 5 Features

* Built-in command support
* cd
* pwd
* help
* clear
* exit
* Environment variables
* env

## Week 6 Features

* Signal handling
* SIGINT support
* SIGCHLD support
* Zombie cleanup
* Shell survives Ctrl+C

## Build

```bash
make
```

## Run

```bash
make run
```
